# Contributing

Press is a personal library with a deliberately narrow scope. To keep it that way, contributions are limited to security fixes.

## Security reports

If you've found a vulnerability, please report it privately through GitHub Security Advisories:

<https://github.com/ahokinson/press/security/advisories/new>

Do not open a public issue for security problems.

## Other contributions

Non-security pull requests will be closed unmerged. This isn't personal — it's the only way to keep maintenance sustainable.

Bug reports and design feedback are welcome via [issues](https://github.com/ahokinson/press/issues), but please don't expect a fix to land unless it has security implications.
